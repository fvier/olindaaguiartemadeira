# 🛡️ Política de Backup 3-2-1 (Olinda Aguiar)

Diretrizes de proteção e retenção para o código-fonte, documentos e ativos visuais em alta resolução de **Olinda Aguiar — Artes em Madeira**.

---

## 1. Regra 3-2-1 de Backup
- **3 Cópias dos Dados**:
  1. Cópia local de desenvolvimento.
  2. Cópia em repositório remoto GitHub (`fvier/olindaaguiartemadeira`).
  3. Cópia externa de segurança (Cold Storage / Nuvem).
- **2 Meios Físicos / Lógicos Distintos**:
  - Armazenamento local (SSD da estação de trabalho).
  - Nuvem GitHub / Storage offsite para mídias pesadas.
- **1 Cópia Offsite**:
  - Armazenamento remoto geograficamente distribuído.

---

## 2. Proteção de Ativos Visuais
- Os arquivos da pasta `referencias/` (fachadas, logotipos e peças fotográficas de alta definição) devem manter redundância em nuvem para prevenir perdas acidentais de patrimônio criativo.
